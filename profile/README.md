# OnePane

**Multi-cloud and on-prem infrastructure monitoring, priced mostly per seat — not a flat per-host tax.**

[Website](https://onepane.dev) · [Pricing](https://onepane.dev#pricing)

</div>

---

OnePane watches AWS, GCP, Azure, and on-prem racks from a single dashboard. One lightweight agent reads the Prometheus metrics you already expose — no cloud vendor lock-in, no per-host pricing tax.

We're early: a small, founder-led team working with our first design partners before a wider launch. Public repositories here will grow as the project does.

### What we're building

- **Coverage** — one agent, every environment: cloud instances, bare metal, and Kubernetes nodes in one view.
- **Alerting** — route by service and severity to Slack, PagerDuty, webhooks, or email, defined in a file you control.
- **Pricing** — a base platform fee plus modest per-host and per-seat overage, instead of a flat per-host tax that punishes a growing fleet.

Managed cloud is available today, in design-partner access.
